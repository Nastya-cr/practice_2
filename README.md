# Визуализатор зависимостей Cargo

Учебное CLI-приложение для получения зависимостей пакетов Rust.

Программа читает настройки из TOML-файла, обращается к Cargo-индексу
и выводит прямые зависимости указанной версии пакета.

## Возможности

На текущем этапе программа умеет:

- читать настройки из `config.toml`;
- проверять правильность настроек;
- получать сведения о Rust-пакете по URL;
- находить указанную версию пакета;
- выводить его прямые зависимости;
- обрабатывать ошибки конфигурации и репозитория.

Программа использует только стандартную библиотеку Python. Менеджер
пакетов Cargo и сторонние библиотеки для получения зависимостей не
используются.

## Требования

Необходим Python 3.11 или новее.

Для сохранения PNG требуется Graphviz (команда `dot`).
На macOS его можно установить командой `brew install graphviz`.

## Настройки

Настройки находятся в файле `config.toml`.

Пример:

```toml
package_name = "serde"
repository = "https://index.crates.io/"
test_mode = false
version = "1.0.0"
ascii_tree = true
max_depth = 3
filter_substring = ""
```

Описание параметров:

- `package_name` — имя анализируемого Rust-пакета;
- `repository` — URL Cargo-индекса или путь к тестовому файлу;
- `test_mode` — использование тестового репозитория;
- `version` — анализируемая версия пакета;
- `ascii_tree` — включение будущего вывода ASCII-дерева;
- `max_depth` — будущая максимальная глубина обхода зависимостей;
- `filter_substring` — будущая подстрока для исключения пакетов.

Параметры `ascii_tree`, `max_depth` и `filter_substring` понадобятся
на следующих этапах работы.

## Запуск

Запуск через скрипт:

```bash
./run.sh
```

Или напрямую через Python:

```bash
python3 src/main.py
```

При запуске программа сохраняет граф в `graph.png` в рабочей папке.
Следующий запуск заменяет этот файл. Для проверки без доступа к Cargo-индексу:

```bash
sh run.sh examples/test_config.toml
```

Программа выводит прямые зависимости в следующем виде:

```text
Прямые зависимости package version:
- dependency ^1.0 (normal)
- optional-dependency ^2.0 (normal, optional)
```

## Описание файлов

### `src/main.py`

Запускает программу, загружает настройки, получает зависимости
и выводит результат.

Функции:

- `main()` — управляет запуском программы;
- `print_dependencies()` — выводит найденные зависимости.

### `src/config.py`

Загружает и проверяет настройки.

Функции:

- `load_config()` — читает TOML-файл;
- `_get_text()` — проверяет текстовую настройку;
- `_get_bool()` — проверяет логическую настройку;
- `_get_depth()` — проверяет максимальную глубину;
- `_validate_repository()` — проверяет URL или путь;
- `validate_config()` — запускает проверку всех настроек.

### `src/cargo.py`

Получает данные из Cargo-индекса.

Функции:

- `_index_path()` — создаёт путь пакета внутри индекса;
- `_build_url()` — создаёт полный URL пакета;
- `_download_index()` — загружает данные пакета;
- `_parse_versions()` — разбирает полученный JSON;
- `_find_version()` — находит указанную версию;
- `get_direct_dependencies()` — возвращает прямые зависимости.

## Обработка ошибок

Программа сообщает об ошибке, если:

- файл `config.toml` отсутствует;
- TOML заполнен неправильно;
- отсутствует обязательная настройка;
- значение настройки имеет неправильный тип;
- пакет не найден;
- версия пакета не найдена;
- репозиторий недоступен;
- репозиторий вернул неправильные данные.
